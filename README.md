## Contributing

Contributions are warmly welcome! 🙌

1. Fork the repo
2. Add your tool to the appropriate section (keep the table format consistent)
3. Make sure the link works and isn't a duplicate
4. Open a Pull Request with a short description of what the tool does

**Guidelines:**
- One row per tool, alphabetical order within categories is appreciated but not required
- Description should be 1 short sentence (under ~80 characters)
- Prefer the official site over aggregator links
- No affiliate or referral links
